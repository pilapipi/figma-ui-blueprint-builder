# Support

## Usage and design questions

Use [GitHub Discussions](https://github.com/pilapipi/figma-ui-blueprint-builder/discussions)
for:

- installation and Figma Development Plugin setup;
- Blueprint modeling questions;
- workflow and component decomposition guidance;
- ideas that are not yet concrete feature requests.

## Bugs

Use the bug report template in
[GitHub Issues](https://github.com/pilapipi/figma-ui-blueprint-builder/issues).
Include a minimal, non-confidential Blueprint and exact reproduction steps.

## Security

Do not use Issues or Discussions for vulnerabilities. Follow
[SECURITY.md](./SECURITY.md).

## Commercial support

This open-source repository does not include guaranteed response times,
implementation services, design migration, or private product support.
