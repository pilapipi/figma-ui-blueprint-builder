# Governance

Figma UI Blueprint Builder is stewarded by 广州派拉披披科技有限公司
(`pilapp`) with participation from the community.

## Roles

- **Contributors** submit Issues, Discussions, documentation, examples, and
  pull requests.
- **Maintainers** review contributions, triage reports, manage releases, and
  protect the runtime's domain-neutral architecture.
- **Project stewards** at pilapp make final decisions on project scope,
  security, governance, and trademark use.

## Decision making

Routine changes are decided through pull request review. Maintainers seek
technical consensus and consider:

- whether the capability is reusable across products;
- Blueprint compatibility;
- Figma runtime safety;
- maintenance and security cost;
- documentation and test coverage.

If consensus is not reached, pilapp project stewards make the final decision
and document the reasoning in the relevant Issue or pull request.

## Becoming a maintainer

Maintainer access may be offered to contributors who consistently demonstrate:

- sound technical judgment;
- respectful collaboration;
- reliable review and follow-through;
- care for privacy, security, and backward compatibility.

Repository permissions are granted and revoked by pilapp project stewards.

## Releases

Maintainers publish semantic versions after required checks pass. Security
releases may use an accelerated private remediation process before coordinated
public disclosure.
