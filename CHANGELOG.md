# Changelog

All notable changes are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [2.0.0] - 2026-07-31

### Added

- Generic Blueprint 1.0 runtime for editable Figma components and screens.
- Tokens for colors, typography, spacing, and radii.
- Component instances, text overrides, Auto Layout, gradients, SVG, and image
  layers.
- Local screenshot reference placement and Figma selection inspection.
- JSON Schema and semantic Blueprint validation.
- Project scaffolding and review templates.
- English and Simplified Chinese documentation.
- Open-source governance, contribution, support, conduct, and security policy.

### Security

- Figma plugin network access remains disabled.
- Client asset directories are ignored by Git by default.
- CI validates source, tools, examples, Schema, and TypeScript output.
